## Start here: three repos you can run in 30 seconds

Each runs offline with Python 3.10 or newer, no packages and no API key.

| Repo | What it shows |
|---|---|
| [**ai-product-evals**](https://github.com/aragjha/ai-product-evals) | Should the new prompt ship? A written release rule says HOLD, and why. |
| [**claude-pm-os**](https://github.com/aragjha/claude-pm-os) | Meeting notes to brief, tickets, QA checklist and release note, with a human gate at each step. |
| [**clinical-extraction-lab**](https://github.com/aragjha/clinical-extraction-lab) | Every extracted decision points at its evidence; doubtful items go to a reviewer. Synthetic notes. |

Results in these repos are labelled **fixture**: produced by a deterministic stand in, not a language model, so anyone can reproduce them for free. Live Claude runs are built and tested but not run yet; each README says so.

Also: [**prodman-stack**](https://github.com/aragjha/prodman-stack), an open source Claude Code toolkit for product managers: 15 skill packs (bundles of instructions Claude follows) and 56 workflows behind one `/pm` command.

## What I do

- **Lead.** I own strategy and the roadmap for six AI products and lead the product managers, designers and engineers who build them.
- **Ship.** I build the first prototype myself, inside the product's real codebase, so engineers start from working software. Then I measure what the product changes.
- **Build with Claude.** My product work runs through Claude Code agents: notes become tickets, tickets become prototypes, and nothing reaches Jira without my review.
- **Decide with evals.** A fixed test set, graders written before the run, and a release rule agreed before anyone sees the result.

I built the prototype and lead the product. 2.5M records processed and 23K+ decisions signed by human reviewers. *Measured: production database, all time to Jul 2026; a record is one clinical note, a decision is one item a reviewer accepted or changed.*

*Measured* means counted from a system of record or a public listing. I publish no accuracy figure unless each prediction was checked against its own correct answer. The repos above contain no employer code, data or prompts; the numbers in this section describe my work, not those repos.
